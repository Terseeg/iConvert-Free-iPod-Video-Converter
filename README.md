# iConvert-Free-iPod-Video-Converter
Have you ever had a video so great, you wanted to put it... on an iPod... for some reason..? You're in luck! iConvert is a free vibe-coded masOS app that converts video files to be compatible with iPod Video (5G / 5.5G), iPod nano (3G), iPod classic (6G / 7G) &lt;- 67!, and iPod 3G (audio only)!
